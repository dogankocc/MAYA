React Native uygulaması (chat_rn) sadece arayüz. Asıl LLM (yapay zeka modeli) PC’deki C++ programında çalışır.

Telefon/Emulator (chat_rn)  →  HTTP  →  PC (CMakeProject2.exe serve)  →  LLM modeli
Uygulama mesajı sunucuya gönderir; sunucu modeli çalıştırıp cevabı döner. Sunucu olmadan uygulama “Bağlantı yok” gösterir.

Nasıl çalıştırılır?
1. Projeyi derle (ilk kez)
cd c:\Users\dogan.koc\source\repos\CMakeProject2
cmake --build out\build\x64-debug
2. Model oluştur (ilk kez, model dosyası yoksa)
out\build\x64-debug\CMakeProject2\CMakeProject2.exe demo
Bu komut şunları üretir:

model.ckptq — quantize edilmiş model
tokenizer_data — tokenizer
3. Sunucuyu başlat
cd c:\Users\dogan.koc\source\repos\CMakeProject2
out\build\x64-debug\CMakeProject2\CMakeProject2.exe serve --model model.ckptq --tokenizer tokenizer_data --port 8765
Başarılı olursa şunu görürsün:

LLM server listening on http://127.0.0.1:8765
Bu pencere açık kalmalı.

4. Uygulamayı başlat (ayrı terminal)
cd c:\Users\dogan.koc\source\repos\CMakeProject2\chat_rn
npx expo start --android
